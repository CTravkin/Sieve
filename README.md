# Sieve

[Русский](README.md) · [English](README.en.md)

Плагин Obsidian для исключения файлов и каталогов перед индексацией хранилища.

## Статус

Разработка первой версии. Реализован общий matcher с нативным oracle; ранний обход проверяется отдельной диагностической пробой Windows. Интеграция движка в плагин, настройки и отображаемые имена еще в работе; устанавливаемого релиза нет.

Версия разработки — `0.3.0 (3)`. Диагностическая проба предназначена только для отдельного тестового хранилища и использует классификатор префиксов. [Команды и границы проверки](Tools/TOOLS.md).

## Функции

Согласованный объем: ранняя фильтрация с полным синтаксисом Syncthing, подробная справка и отображаемое имя текущего хранилища. Интерфейс будет на английском и русском языках. Требования и ограничения описаны в [Requirements](Docs/Requirements.md).

## Платформы

Целевые платформы — Windows, macOS, Linux, iOS и Android. Общий matcher сравнен с Syncthing 2.1.6 на Windows и Linux; native Obsidian-проба проверена на Windows. Это разные проверки. Состояние интеграции отражено в [Compatibility](Docs/Compatibility.md). `minAppVersion: 1.14.4` задает целевой минимум.

## Эксплуатация

### Проверка

Проверки материалов требуют Node.js 22 или новее и не требуют установки зависимостей. Для TypeScript/core нужны `npm.cmd ci`, для native oracle — Go 1.27.0; версии и профили зафиксированы в [Oracle](Tools/Oracle/README.md).

```powershell
npm.cmd run check
npm.cmd test
npm.cmd run typecheck
npm.cmd run test:core
npm.cmd run test:oracle
```

На других платформах используйте команды npm без `.cmd`. `check`/`test` проверяют материалы и диагностические hooks; `typecheck`/`test:core`/`test:oracle` — общий движок. Native Obsidian, системный I/O и UI требуют отдельных сценариев.
