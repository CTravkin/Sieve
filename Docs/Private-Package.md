# Приватный пакет Sieve

Сборка предназначена для закрытых испытаний. Публичного релиза нет. Общий matcher проверен на Windows и Linux; ранний runtime и UI предыдущих сборок — на Windows Obsidian 1.14.4. Проверки других платформ не выполнены. Нативная проверка каждой версии и UI требуется отдельно.

При переименовании ранее видимого скрытого файла Sieve сохраняет штатное обновление ссылок Obsidian, включая возврат файла или папки в индекс. Скрытые цели остаются вне публичного индекса; неоднозначные ссылки не привязываются к цели предположительно.

На Windows 1.14.4 в проверке массовых внешних атомарных замен наблюдалась потеря уведомлений нативного watcher и устаревший `cachedRead`, в том числе на отдельных нативных Adapter/Vault без hooks Sieve при наблюдении того же корня. Sieve не добавляет глобальный опрос файлов или принудительную очистку кеша. Полная приемка массовой синхронизации остается открытой; программный API-тест не заменяет проверки редактора и мобильных устройств.

## Установка

1. Полностью закрой тестовое хранилище Obsidian.
2. Распакуй папку `sieve` из ZIP в `<configDir>/plugins/`, обычно `.obsidian/plugins/`. Внутри `sieve` должны находиться `main.js` и `manifest.json`.
3. Включи Sieve в настройках сторонних плагинов и полностью переоткрой хранилище. Первое включение происходит после загрузки индекса; ранняя фильтрация начнется при следующем открытии.
4. Задай правила в настройках Sieve. Успешное сохранение предложит перезагрузить хранилище; выбор «Отложить» оставит прежние правила активными. Справка по синтаксису доступна без сети.

Для обновления заменяй только файлы пакета. Сохрани `data.json` и `data.previous.json` своего хранилища. `identity.json` содержит Git SHA, версии инструментария и хеши файлов сборки. Публичная версия назначается отдельно.

## Ручная настройка и восстановление

Настройки находятся в `<configDir>/plugins/sieve/data.json`:

```json
{
  "schemaVersion": 1,
  "rules": "Technical",
  "displayName": ""
}
```

Пустые правила открывают обычный набор документов с семантикой matcher Sieve; пустое имя использует имя папки. Файлы не удаляются. Ручные изменения правил применяются после полного переоткрытия.

При сохранении измененных настроек хранится одна предыдущая рабочая конфигурация, включая содержимое `#include`. При ошибке нового конфига Sieve использует ее и показывает сообщение. Без рабочего снимка хранилище открывается без фильтрации с ошибкой. После отключения Sieve полностью переоткрой хранилище для восстановления обычного индекса.

Приватная упаковка не публикует репозиторий, не создает release и не устанавливает плагин в рабочее хранилище.
