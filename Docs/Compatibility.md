# Совместимость Sieve

## Текущая граница доказательств

Версия `0.3.0 (3)` содержит общий matcher и диагностический desktop prefix-fixture; полного runtime еще нет. Объявленные в manifest минимум и mobile support остаются целями. Matcher сравнен с native oracle на Windows и Linux: 5952 набора, 34351 результат сопоставления с четырьмя флагами, без расхождений. На Linux прошли все 38 Core/Oracle тестов, включая реальные symlink/include и POSIX permission denial; Windows сохраняет два соответствующих пропуска.

| Платформа | Доступность | Проверка | Результат |
| --- | --- | --- | --- |
| Windows, Obsidian API 1.14.4 | Локальный нативный хост | async onload до обхода, pruning/разрешенный потомок, cached metadata, disable/reopen, события и rename файла/папки, сохранение через удержанные ссылки, первый/последний plugin, alternate configDir, хеши | Частичная проверка кандидата прошла; полный гейт не пройден |
| Linux | BUF-2/SPB-3, Ubuntu 24.04.5 LTS x86_64 | Obsidian/Xvfb не найдены в стандартных путях; GUI-службы неактивны. Нестандартные установки не исключены | Native NOT_TESTED |
| iOS/iPadOS | iPhone/iPad, vault в локальной папке по сообщению Constantine | Native initial fast/fallback, watcher и resume еще не проверены | NOT_TESTED |
| Android | Устройство не подтверждено | Не выполнено | NOT_TESTED |
| macOS | Хост не подтвержден | Не выполнено | NOT_TESTED |

На mobile проба не устанавливает desktop filter. Результат unsupported означает отсутствие реализации этой пробы для mobile, а не доказанную невозможность ранней фильтрации хоста.

Разработка общего движка продолжается по разрешению Constantine. Гипотезы по API/коду не считаются native подтверждением. Сам Obsidian закрыт; открытый API и доступный установленный bundle дают отдельные, ограниченные источники доказательств.

## Восстановление

Отключение Sieve снимает hooks; для полного восстановления индекса требуется полностью переоткрыть vault. Windows fixture подтвердил восстановление исходного состава metadata/index без изменения документов. При первой установке плагин еще не включен до старта; применять фильтрацию до его первой загрузки нельзя.

Alias не реализован. Constantine требует кастомные названия всех vault в меню переключения; подписи только текущего vault недостаточно. Стартовый менеджер до загрузки плагина остается отдельной неподтвержденной поверхностью. Совпадение общего matcher с Syncthing 2.1.6 подтверждено проверенным differential-корпусом; интеграция этого matcher в приложение требует отдельной проверки.
