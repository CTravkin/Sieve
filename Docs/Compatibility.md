# Совместимость Sieve

## Текущая граница доказательств

Версия `0.6.4 (17)` содержит общий matcher, ранний runtime, vault-local настройки, EN/RU UI и проекции имен. Runtime проверен в Windows Obsidian на сборке 9, настройки — на 10/12, отдельные UI-поверхности имен — на 14. После этого исправлены снятие hooks при ошибке и предложение reload после fallback; эти изменения прошли модель и ревью, но еще не новый native запуск. Объявленные в manifest минимум и mobile support остаются целями. Matcher сравнен с native oracle на Windows и Linux: 5952 набора, 34351 результат сопоставления с четырьмя флагами, без расхождений. На Linux прошли все 38 Core/Oracle тестов, включая реальные symlink/include и POSIX permission denial; Windows сохраняет два соответствующих пропуска.

Mobile-кандидат использует отдельный управляемый начальный обход вместо массового `watchAndStatAll`. Модель адаптера прошла; native fast/fallback, watcher и resume на устройстве остаются непроверенными. Диагностическая prefix-проба desktop не доказывает мобильную поддержку.

Разработка общего движка продолжается по разрешению Constantine. Гипотезы по API/коду не считаются native подтверждением. Сам Obsidian закрыт; открытый API и доступный установленный bundle дают отдельные, ограниченные источники доказательств.

## Восстановление

Отключение Sieve снимает hooks; для полного восстановления индекса требуется полностью переоткрыть vault. Windows fixture подтвердил восстановление исходного состава metadata/index без изменения документов. При первой установке плагин еще не включен до старта; применять фильтрацию до его первой загрузки нельзя.

Alias реализован для подписи текущего vault, заголовка окна, drawer и двух команд переключения с поиском. Каждый vault читает имя из собственного конфига; пути, IDs, URI и `getName` сохраняются. Desktop native-контракт Obsidian 1.14.4 и модель подтверждены; часть UI проверена на 14, полный native gate не закрыт. `getAliasCapabilities` отдельно сообщает доступность поверхностей. Недоступный/ошибочный конфиг оставляет исходное имя. Mobile-provider и другие override configDir остаются гипотезами: без подтвержденного ID используется только доступный стандартный `.obsidian`. Стартовый менеджер до загрузки плагина использует нативные имена.

## Оставшиеся нативные проверки

Constantine остановил управление мышью и разрешил только API без мыши, клавиатуры и переключения фокуса; UI перепроверит позже. Тестовый Obsidian штатно закрыт через API, конфиги и реестр восстановлены, 6624 документа и пакет 14 сверены по хешам. Проверенный main приложения вызывает show/focus; скрытый Start-Process не гарантирует отсутствие захвата фокуса. Поэтому новые native запуски, повторный benchmark и install/upgrade кандидата отложены. Это ограничение проверки, а не подтверждение совместимости.
