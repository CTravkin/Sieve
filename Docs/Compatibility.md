# Совместимость Sieve

## Текущая граница доказательств

Диагностическая версия `0.2.0 (2)` проверяет desktop prefix-fixture, а не полный фильтр. Объявленные в manifest минимум и mobile support остаются целями.

| Платформа | Доступность | Проверка | Результат |
| --- | --- | --- | --- |
| Windows, Obsidian API 1.14.4 | Локальный нативный хост | async onload до обхода, отсечение и разрешенный потомок, cached metadata, disable/reopen, хеши | Частичная проверка кандидата прошла; полный гейт не пройден |
| Linux | Удаленные хосты есть по сообщению Constantine | Desktop Obsidian/GUI еще не проверены | NOT_TESTED |
| iOS/iPadOS | iPhone/iPad есть по сообщению Constantine | Native initial fast/fallback, watcher, Files provider и resume еще не проверены | NOT_TESTED |
| Android | Устройство не подтверждено | Не выполнено | NOT_TESTED |
| macOS | Хост не подтвержден | Не выполнено | NOT_TESTED |

На mobile проба не устанавливает desktop filter. Результат unsupported означает отсутствие реализации этой пробы для mobile, а не доказанную невозможность ранней фильтрации хоста.

## Восстановление

Отключение Sieve снимает hooks; для полного восстановления индекса требуется полностью переоткрыть vault. Windows fixture подтвердил восстановление исходного состава metadata/index без изменения документов. При первой установке плагин еще не включен до старта; применять фильтрацию до его первой загрузки нельзя.

Alias не реализован. Область отображаемого имени, включая стартовый менеджер, должна быть проверена и согласована отдельно. Полную совместимость с Syncthing 2.1.6 можно заявлять только после differential oracle этапа 2.
