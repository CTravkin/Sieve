# Совместимость Sieve

## Текущая граница доказательств

Версия `0.6.1 (14)` содержит общий matcher, ранний runtime, vault-local настройки, EN/RU UI и проекции имен. Настройки проверены в настоящем Windows Obsidian; alias прошел модель, нативная проверка продолжается. Объявленные в manifest минимум и mobile support остаются целями. Matcher сравнен с native oracle на Windows и Linux: 5952 набора, 34351 результат сопоставления с четырьмя флагами, без расхождений. На Linux прошли все 38 Core/Oracle тестов, включая реальные symlink/include и POSIX permission denial; Windows сохраняет два соответствующих пропуска.

| Платформа | Доступность | Проверка | Результат |
| --- | --- | --- | --- |
| Windows, Obsidian API 1.14.4 | Локальный нативный хост | Полный matcher в раннем runtime, cached metadata, события/редактор/удержанные ссылки, синхронные callbacks и FileExplorer, FIFO/ABA, порядок плагинов и alternate configDir; EN/RU настройки, Save/Reload, fallback и автоматическая внешняя правка | Runtime и UI проверены на синтетических данных; native alias, benchmark и полный платформенный гейт еще не завершены |
| Linux | BUF-2/SPB-3, Ubuntu 24.04.5 LTS x86_64 | Obsidian/Xvfb не найдены в стандартных путях; GUI-службы неактивны. Нестандартные установки не исключены | Native NOT_TESTED |
| iOS/iPadOS | iPhone/iPad, vault в локальной папке по сообщению Constantine | Native initial fast/fallback, watcher и resume еще не проверены | NOT_TESTED |
| Android | Устройство не подтверждено | Не выполнено | NOT_TESTED |
| macOS | Хост не подтвержден | Не выполнено | NOT_TESTED |

Mobile-кандидат использует отдельный управляемый начальный обход вместо массового `watchAndStatAll`. Модель адаптера прошла; native fast/fallback, watcher и resume на устройстве остаются непроверенными. Диагностическая prefix-проба desktop не доказывает мобильную поддержку.

Разработка общего движка продолжается по разрешению Constantine. Гипотезы по API/коду не считаются native подтверждением. Сам Obsidian закрыт; открытый API и доступный установленный bundle дают отдельные, ограниченные источники доказательств.

## Восстановление

Отключение Sieve снимает hooks; для полного восстановления индекса требуется полностью переоткрыть vault. Windows fixture подтвердил восстановление исходного состава metadata/index без изменения документов. При первой установке плагин еще не включен до старта; применять фильтрацию до его первой загрузки нельзя.

Alias реализован для подписи текущего vault, заголовка окна, drawer и двух команд переключения с поиском. Каждый vault читает имя из собственного конфига; пути, IDs, URI и `getName` сохраняются. Desktop native-контракт Obsidian 1.14.4 и модель подтверждены; нативный UI-проход еще выполняется. `getAliasCapabilities` отдельно сообщает доступность поверхностей. Недоступный/ошибочный конфиг оставляет исходное имя. Mobile-provider и другие override configDir остаются гипотезами: без подтвержденного ID используется только доступный стандартный `.obsidian`. Стартовый менеджер до загрузки плагина использует нативные имена.
