# Версии и сборки Sieve

## Источник

Версия релиза и номер сборки пока не назначены. `package.json` и `manifest.json` не содержат версии, `sieveBuild` отсутствует, `versions.json` пуст. Это заготовка исходников; manifest без обязательной версии не подходит для установки.

Начало нумерации и первая версия определяются Constantine после подготовки плана. Не назначаем числовые заглушки и не прогнозируем число сборок до релиза.

После назначения `package.json` будет хранить `version` и целочисленный `sieveBuild`. Отображаемый формат — `X.Y.Z (N)`. Копия `X.Y.Z` в `manifest.json` должна совпадать с package; `versions.json` сопоставляет выпуски минимальной версии Obsidian.

## Правила проекта

- X задает Constantine.
- Y увеличивается при новой возможности; Z — при исправлении. При увеличении верхней части нижние сбрасываются.
- N увеличивается для каждого недокументального коммита/новой сборки исходников. Повторная компиляция того же SHA сохраняет номер; docs-only изменения его не повышают.
- В пределах одной Y недокументальные ревизии получают следующий Z, чтобы разные сборки не публиковались под одной версией Obsidian.
- Версионный коммит начинается с `X.Y.Z (N)`. Документальный коммит может не иметь версионного префикса.

## Требования Obsidian

Manifest и тег релиза используют только `X.Y.Z`: без `v`, номера сборки, суффикса prerelease или build metadata. Имя релиза может содержать `X.Y.Z (N)`. Нельзя переиспользовать опубликованный тег для другой сборки.

Для релиза нужны `main.js`, `manifest.json` и при наличии `styles.css`; совместимость в `versions.json` обновляется вместе с версией. До установки и реальных проверок нельзя выдавать заготовку за рабочий релиз.

Источник: [публикация плагинов Obsidian](https://docs.obsidian.md/Plugins/Releasing/Submit%20your%20plugin), [схема manifest](https://docs.obsidian.md/Reference/Manifest).

## Начальное состояние

Версия и сборка не назначены; релиз и тег не создавались. Репозиторий остается приватным; публикация первой версии и лицензия требуют отдельного решения владельца.
